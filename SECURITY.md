# Security Policy

## Supported Versions

The following table outlines the versions of `GreetKit` currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `GreetKit` and its Intent-Driven Development (IDD) execution pipeline seriously.

If you discover a security vulnerability in GreetKit, its CLI commands, or agent skills:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately by emailing the maintainers or submitting a private security advisory via GitHub.
3. Include detailed steps to reproduce the issue, along with any relevant proof-of-concept scripts or command outputs.

### Response Policy

- **Initial Response:** Within 48 hours of receiving a vulnerability report.
- **Status Update:** Regular updates every 3 business days until resolved.
- **Fix Release:** Vulnerabilities will be patched in a dedicated patch release as quickly as possible.

Thank you for helping keep GreetKit and its open-source community secure!
